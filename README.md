# Online Examination System

This is a web-based Online Examination System designed to help conduct tests digitally. It includes features like user registration, question management, test-taking, and result generation.

## Features

- Admin dashboard for managing questions and tests.
- Student login to take exams.
- Result analysis and reporting.
- Secure login system.

## Technologies Used

- Python, TKinter

## How to Run the Project

1. Extract the ZIP file.
2. Run the main file
